Elige el proyecto a configurar

La segmentación se configura por proyecto. Selecciona con cuál quieres trabajar.

Configuración de segmentación

Define cómo se parten los textos largos en fragmentos etiquetables. Esta configuración se aplica al corpus completo del proyecto antes de dividir en paquetes.

Parámetros

Identifica esta configuración si más adelante quieres tener varias (p. ej. "Estricta" para campo abierto, "Laxa" para resúmenes).
Recomendado: palabra o frase. Token es para textos técnicos; párrafo para respuestas estructuradas.
Si el texto excede este tamaño, se parte en varios fragmentos.
Caracteres de solapamiento entre fragmentos consecutivos. Útil para mantener contexto entre cortes.
Si está activo, nunca se parte una palabra/frase. Si está desactivado, el corte es por tamaño exacto.
Porcentaje de desvío permitido sobre el tamaño máximo antes de forzar un corte. 0 = exacto.
Tip: El fragmento más pequeño permitido es 10 unidades (palabras/tokens). Si una respuesta tiene menos, queda como un único fragmento.
