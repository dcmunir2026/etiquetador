Crear escala personalizada

Define un tipo de escala propio para esta taxonomía. Quedará guardada para futuras taxonomías.

Como aparecerá al crear taxonomías.
Categórico: el anotador elige de N opciones. Numérico: introduce un número 0-N. Libre: campo abierto.
Entre 1 y 10. Para numérico, será el valor máximo del rango.
